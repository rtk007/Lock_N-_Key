Why does Windows show a SmartScreen warning?

This is expected for unsigned indie software. Here's the full explanation & how to proceed safely.

Windows Defender SmartScreen flags executables that don't yet have a large download reputation. This is a trust-based system, not a virus scan result. Lock N' Key contains no telemetry, no network calls, and no background services. The source code is 100% open on GitHub for inspection.

1

Click "More info" on the SmartScreen popup

When the blue dialog appears, don't close it. Look for the small grey text that says "More info" and click it.

Windows protected your PC

Microsoft Defender SmartScreen prevented an unrecognized app from starting. Running this app might put your PC at risk.

More info › Don't run
2

Click "Run anyway"

After clicking "More info", the dialog expands to show the app name and publisher. A "Run anyway" button will appear at the bottom. Click it to proceed with the installation.

3

Verify integrity (optional but recommended)

You can verify the file hasn't been tampered with by checking its SHA-256 hash before running:

Project Overview

Lock N' Key is a developer-first, local-only password manager built with Flutter Desktop. It prioritizes Zero Trust architecture, ensuring that no data ever leaves the user's device. It is designed to integrate seamlessly into a developer's workflow via global hotkeys and browser extensions.

📁 Directory Structure

lib/
├── main.dart                  # Entry point
├── app.dart                   # Root widget
├── models/                    # Data models (Secret, AuditLog)
├── screens/                   # UI Screens
├── services/                  # Business Logic & Core Services
└── widgets/                   # Reusable UI Components

🏗️ Architecture & Tech Stack

  • Framework: Flutter (Windows Desktop focus)
  • Database: hive_flutter (NoSQL, fast, encrypted)
  • Encryption: encrypt package (AES-256-GCM/CBC)
  • Biometrics: local_auth (Windows Hello)
  • Global Hotkeys: hotkey_manager

🔐 Security Model

The core of Lock N' Key is its "Zero Trust" security model.

1. Key Management

  • Master Key (MK): Random 32-byte key generated on registration.
  • Storage: The MK is never stored in plain text. It is encrypted with your password hash.
  • Session: The decrypted MK is held in memory only while the session is active.

2. Database Encryption

All data in local database boxes is encrypted using the Master Key. Even if the raw files are stolen, they cannot be read without the password.

🛠️ Core Services

1. ServerService (Localhost API)

Runs on port 45454 (Loopback only) to communicate with the Browser Extension. If the vault is locked, it requests user authentication on the desktop app before processing any request.

2. AuditService

Logs every significant action (Decrypt, Export, Access) for security auditing. Logs are stored in an encrypted box.

🚀 Key Features

Quick Access (Alt + Space)

A Spotlight-like overlay to search and paste secrets immediately into your active IDE.

Securely transfer your vault between devices using our encrypted .lnk backup format.
